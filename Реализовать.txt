Ты — генератор обучающих данных для классификатора долгосрочной памяти в диалоговой системе LLM.

Контекст:
Есть CSV-файл dataset_generation/GigaMemory_data/user_messages_labeled+cursor_generate.csv, содержащий пары:

message,label


где:

message — сообщение пользователя в диалоге с LLM

label = 1 — сообщение содержит устойчивую информацию о пользователе, которую имеет смысл сохранить в долгосрочной памяти

label = 0 — сообщение не содержит информации, которую следует сохранять в долгосрочной памяти

Ты изучил существующий файл и знаешь:

какие темы уже присутствуют,

какие формулировки, стили и типы сообщений используются.

Задача

Сгенерировать 1000 НОВЫХ сообщений и дописать их в конец файла user_messages_labeled+cursor_generate.csv.
Просто добавь их в конец файла dataset_generation/GigaMemory_data/user_messages_labeled+cursor_generate.csv самостоятельно. Не нужно сохдавать скрипты, консольные команды и прочее. Не нужно писать новые сообщения сюда.

Старайся придерживаться следующих требований:

Отсутствие пересечений

Старайся чтобы новые сообщения не повторяли:

темы,

факты,

формулировки,

паттерны сообщений
из уже существующего датасета.

Используй совершенно новые домены и жизненные контексты.

Баланс классов

Примерно 50% label = 1, 50% label = 0

Допустимо отклонение ±5%

Разнообразие
Сообщения должны сильно отличаться друг от друга по:

стилю (краткие, развернутые, обрывки фраз),

эмоциональности,

формальности,

степени явности информации.

Естественность

Пиши так, как реально пишут пользователи:

иногда с опечатками,

иногда без заглавных букв,

иногда как продолжение предыдущей реплики,

иногда очень явно и точно.

Часть сообщений должна выглядеть «вырванной из диалога».

Критерии разметки (ОЧЕНЬ ВАЖНО)
label = 1 — сохраняем в память

Сообщение должно содержать устойчивую, персональную информацию, которая:

с высокой вероятностью будет актуальна в будущем,

описывает пользователя, его контекст или ограничения.

Примеры типов информации (НЕ копировать темы из датасета):

необычные профессии или хобби,

редкие бытовые ограничения,

долгосрочные планы,

предпочтения, влияющие на поведение,

особенности образа жизни,

уникальные навыки,

повторяющиеся привычки.

❗ Не каждая личная деталь = label 1
❗ Информация должна быть потенциально полезна для будущих диалогов

label = 0 — не сохраняем

Сообщение не должно содержать полезной долгосрочной информации о пользователе.

Типичные случаи:

вопросы,

эмоции без фактов,

одноразовые события,

рассуждения,

просьбы,

абстрактные комментарии,

ситуативные жалобы или радость.
